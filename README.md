# «Портал» — демо-презентация прототипа

Интерактивная демка **состава первой версии** продукта «Портал»: не витрина
возможностей, а объём работ, который реально войдёт в первый релиз. Всё, чего
нет в списке ниже, показано только одним финальным шагом «Что дальше».

**Live:** https://disregard-therest.github.io/portal-demo/

Структура повторяет [put-demo](https://github.com/Disregard-Therest/put-demo) и
[Mariyana_Anael](https://github.com/Disregard-Therest/Mariyana_Anael): телефон,
шаги сверху, панель пояснений справа.

## Три этапа, 12 шагов

| Этап | Шаги |
| --- | --- |
| **1 · Вход** (синий) | лендинг → входная анкета → твой код → вход по номеру |
| **2 · Продукт** (фиолетовый) | главная, расшифровка, чат с ИИ, подписка и триал |
| **3 · Рост и управление** (розовый) | приглашения экспертов, уведомления, админка, что дальше |

Панель на каждом шаге одной формы: **Что это · Зачем · Почему так, а не иначе · Обсудить**.

Два последних шага, «Админка» и «Что дальше», — не приложение на телефоне
пользователя, а панель, которая работает в браузере. На широком экране они
занимают рамку без корпуса телефона (`PanelFrame` в `lib/presentation/phone_frame.dart`);
в узком режиме показываются как обычный экран, только без нижнего меню.

## Как показывать

- Шаги — бейджами сверху или кнопкой «Дальше»; внутри телефона всё кликабельно,
  панель догоняет сама: номер шага вычисляется из экрана (`AppState.stepIndex`).
- Диплинк на шаг: `?step=10` — открыть сразу приглашения экспертов.
- **На телефоне и в Telegram** рамки нет: приложение во весь экран, сверху полоса
  с шагами (‹ ›, список по нажатию на название) и кнопка «Зачем» с пояснениями.
  Рамка телефона внутри телефона съедала бы треть ширины, а панель под ней пришлось
  бы листать поверх прокручиваемого приложения.
- В `web/index.html` — фикс свайпа для вебвью Telegram (тот же, что в Mariyana_Anael):
  без него свайп вниз сворачивает окно вместо прокрутки.

## Где что лежит

| Что | Где |
| --- | --- |
| Тексты панели пояснений и состав 12 шагов | `lib/data/demo_steps.dart` |
| Пользователь-пример, запросы анкеты, тексты чата | `lib/data/mock_content.dart` |
| Расчёты из даты рождения (нумерология) | `lib/data/astro_math.dart` |
| Состояние демо, «назад», вкладки | `lib/data/app_state.dart` |
| Экраны входа: лендинг, анкета, код, вход | `lib/app/entry_screens.dart` |
| Экраны продукта: главная, расшифровка, чат, подписка | `lib/app/product_screens.dart` |
| Экраны роста и управления: приглашения, пуши, админка, что дальше | `lib/app/ops_screens.dart` |
| Телефон, панель без рамки, раскладка широкая/узкая | `lib/presentation/` |
| Палитра | `lib/theme/app_theme.dart` |

## Что посчитано, а что вписано

Из даты рождения считаются число пути, аркан личности, личный год, личный
месяц и личный день (`lib/data/astro_math.dart`) — это вся математика, которая
нужна первой версии продукта. Знак зодиака, астрологические расчёты и всё, для
чего нужны эфемериды и точное место рождения, в неё не входят: это шаг
«Что дальше», а не текущий экран. Тема месяца, карта дня Ба Цзы, тексты
заданий, цифры приглашений и админки — вписаны вручную, как контент, который
в реальном продукте ведут эксперты и админка.
